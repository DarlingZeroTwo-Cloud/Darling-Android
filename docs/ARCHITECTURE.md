# 架构设计

## 概述

Darling Android 通过 chroot 方式在 Linux 上原生运行 Android 应用，无容器开销，性能更高。

## 系统架构

```
┌─────────────────────────────────┐
│         Linux 桌面环境          │
│  (Wayland / X11)               │
└───────────────┬─────────────────┘
                │
┌───────────────▼─────────────────┐
│      Darling Android 层        │
│  ┌─────────────────────────┐   │
│  │    chroot 环境          │   │
│  │  ┌───────────────────┐ │   │
│  │  │  Android 运行库   │ │   │
│  │  │  (Bionic libc)   │ │   │
│  │  └───────────────────┘ │   │
│  │  ┌───────────────────┐ │   │
│  │  │  ARM 转译层       │ │   │
│  │  │ (libhoudini/libndk)│ │   │
│  │  └───────────────────┘ │   │
│  │  ┌───────────────────┐ │   │
│  │  │  Android 应用     │ │   │
│  │  └───────────────────┘ │   │
│  └─────────────────────────┘   │
└─────────────────────────────────┘
                │
┌───────────────▼─────────────────┐
│         Linux 内核              │
│  (binder / ashmem / GPU驱动)   │
└─────────────────────────────────┘
```

## 核心组件

### 1. chroot 环境
- 隔离 Android 文件系统
- 共享 Linux 内核
- 无容器开销

### 2. Android 运行库
- Bionic libc
- ART 运行时
- 系统服务

### 3. ARM 转译
- Intel CPU: libhoudini
- AMD CPU: libndk
- 自动检测，用户无感

### 4. GPU 加速
- 直接使用 Linux GPU 驱动
- VirGL 或 llvmpipe
- 支持所有显卡

## 数据流

1. 用户执行 `darling install app.apk`
2. 复制 APK 到 chroot 环境
3. 用户执行 `darling run com.example.app`
4. chroot 进入 Android 环境
5. ART 运行时加载 APK
6. ARM 应用通过转译层运行
7. GPU 加速渲染
8. 窗口集成到 Linux 桌面

## 性能优势

- 无容器虚拟化开销
- 直接 GPU 访问
- 共享 Linux 内核
- 接近原生性能
